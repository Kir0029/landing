# 📂 Отчет о выполнении тестового задания: Портфолио-лендинг с AI-ассистентом

Этот проект представляет собой высокопроизводительный, отзывчивый одностраничный лендинг-портфолио для AI-инженера и Python-разработчика. Дизайн выполнен в кастомной светлой стилистике **«Warm Paper»** (кремовая бумага) с интерактивными Canvas-эффектами, встроенной почтовой формой и живым AI-собеседником.

---

## 🛠️ Используемый стек и архитектурные решения

### Frontend
- **Vite 6 + TypeScript 5.8**: Выбраны для обеспечения быстрой сборки, строгой типизации и современной среды разработки.
- **Vanilla JS/TS (без фреймворков)**: Для одностраничного интерактивного лендинга использование React/Vue/Angular было бы избыточным (overkill). Разработка на чистом TypeScript демонстрирует глубокое понимание нативного DOM, событийного цикла браузера и работы с Canvas.
- **Vanilla CSS (Modern Custom Properties)**: Вместо SCSS или Tailwind использован чистый CSS, структурированный по модулям. Это позволило реализовать гибкую темизацию через CSS-переменные, сложные hover-эффекты с градиентными рамками, эффекты матового стекла (glassmorphism) и плавные переходы без лишней компиляции и внешних зависимостей.

### Backend / Serverless API
- **Netlify Functions (Node.js)**: Поскольку у проекта нет выделенного выделенного сервера, бэкенд реализован в виде бессерверных (Serverless) функций. Это обеспечивает бесплатный хостинг, масштабируемость и безопасность API-ключей.
- **Интеграция с Resend API (Почта)**: Для отправки писем используется современный REST API Resend. Запросы отправляются через нативный `fetch` (без тяжелых SDK-библиотек).
- **Интеграция с Google Gemini API (Чат)**: Интегрирована новейшая модель **`gemini-3.1-flash-lite`** через Google AI Studio, оптимизированная под быстрые и экономичные ответы.

## 📡 Реализация API и логика бэкенда

Вся серверная часть находится в каталоге `netlify/functions/` и запускается изолированно.

### 1. Форма обратной связи (`/api/contact`)
- **Валидация**: Перед отправкой бэкенд повторно валидирует входящие данные (длина имени, корректность email, длина сообщения).
- **Rate Limiting (Защита от спама)**: Встроен локальный in-memory ограничитель частоты запросов. Один IP-адрес может отправить не более 3 сообщений в минуту, предотвращая DDoS формы.
- **Заголовки и шаблоны**: Письмо генерируется в виде красивой сверстанной HTML-карточки. Для удобства общения добавлен заголовок `reply_to` с адресом отправителя — владелец может нажать кнопку «Ответить» прямо в своем почтовом клиенте, чтобы начать переписку.

### 2. ИИ-ассистент (`/api/chat`)
- **Управление контекстом**: Функция принимает историю сообщений и текущий вопрос. На бэкенде к запросу добавляется детальный `SYSTEM_PROMPT` с резюме Кирилла, его проектами (с ключевыми метриками), стеком технологий и контактами.
- **Совместимость и Fallback**: Реализована поддержка API Google Gemini (`gemini-3.1-flash-lite`). При отсутствии ключей бэкенд отдает статус `503 Service Unavailable`, и клиентская часть сайта бесшовно переключается на **локальный оффлайн-режим (mock-mode)**, отвечая на вопросы пользователя на основе заготовленной базы знаний Кирилла.

## 🤖 Роль ИИ и ручные доработки (AI + Человек)

Проект создавался в тесном сотрудничестве с искусственным интеллектом (агенты Antigravity 2.0), однако финальный лоск и ключевые доработки производились вручную для обеспечения высшего качества.

Использованные модели:
- **Claude Opus 4.6**: для первичного анализа и сбора основных фаз.
- **Gemini 3.5 Flash**: для основной работы и полировки.

### Что было сделано с помощью ИИ:
- Генерация базовой структуры проекта, конфигурационных файлов и шаблонов стилей.
- Базовая логика Canvas-анимации частиц и утилит плавного скролла.
- Генерация графических ассетов (аватар разработчика в стиле flat-vector и круглый аватар ассистента) с помощью нейросетей.
- Первичный копирайтинг текстов и описаний проектов.

### Что пришлось исправлять и дорабатывать вручную:
1. **Переход на кастомную тему «Warm Paper»**: Исходный сгенерированный шаблон выглядел стандартно (темная тема, фиолетовые тона). Вручную переработана вся палитра: внедрен благородный кремовый фон, контрастные белые карточки, кофейный цвет шрифтов и терракотовые акценты. Перенастроены все тени и рамки под светлый дизайн.
2. **Динамический цвет частиц на Canvas**: В исходном скрипте цвет частиц и линий связи был жестко прописан в JS-коде (синий цвет). Скрипт переписан так, чтобы он считывал CSS-переменную `--color-primary-rgb` на лету. Теперь при смене темы в файле стилей частицы автоматически меняют цвет.
3. **Верстка имитатора терминала в Hero**:
   - Исправлен баг «склеивания» inline-тегов `span` в HTML, из-за которого браузер рендерил лишние пробелы вокруг двоеточий и запятых в JSON-коде.
   - Свойство сохранения пробелов `white-space: pre-wrap` перенесено на конкретные строки кода, что убрало гигантские пустые пространства, вызванные отступами самого редактора кода.
   - Из JSON удален невалидный комментарий `//`, делавший структуру некорректной.
4. **Центрирование заголовков секций**: Полностью переработана структура заголовков. Создан класс `.section-header` для центрирования названий разделов, а для меток (например, «Кейсы») добавлены декоративные линии с двух сторон через псевдоэлементы `::before` и `::after`.
5. **Интерактивные аватары**: 
   - Анимация вращения рамки аватара заменена на премиальное пульсирующее свечение.
   - Создан двойной аватар: женский ИИ-ассистент вынесен на плавающую кнопку открытия чата (с индикатором онлайн-статуса) и в заголовок чата, а мужской аватар установлен в секцию «Обо мне».

## 🚀 Как запустить проект локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` в корне проекта (по шаблону `.env.example`) и добавьте ваши ключи:
   ```env
   GEMINI_API_KEY=ваш_ключ_google_ai_studio
   RESEND_API_KEY=ваш_ключ_resend
   CONTACT_EMAIL=почта_получателя_писем
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере: `http://localhost:3000/`.

## ☁️ Инструкция по деплою на Netlify

1. Залейте код в ваш GitHub репозиторий (файл `.env` автоматически игнорируется и не попадет в открытый доступ).
2. Зарегистрируйтесь на [Netlify.com](https://www.netlify.com/) через ваш GitHub-аккаунт.
3. Нажмите **Add new site** -> **Import an existing project** -> выберите репозиторий проекта.
4. Настройки сборки подтянутся автоматически из `netlify.toml` (Build: `npm run build`, Publish: `dist`). Нажмите **Deploy site**.
5. Задайте секретные ключи: перейдите в **Site Configuration** -> **Environment variables** и добавьте переменные `GEMINI_API_KEY`, `RESEND_API_KEY` и `CONTACT_EMAIL` с соответствующими значениями.
6. Перейдите во вкладку **Deploys** -> нажмите **Trigger deploy** -> **Clear cache and deploy site**, чтобы Netlify пересобрал функции с новыми ключами.
7. В **Domain management** -> **Change site name** вы можете бесплатно сменить имя поддомена на уникальное.
